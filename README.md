# SandTiger Research takehome project

Quick implementation as of the specifications of the takehome

## Dependencies
- Java 8 (Dockerfile uses Amazon Corretto 8)
- Gradle 6.9
- JUnit 5.10.0

## Building and Running 

### Using Docker 

1. **Build the Docker image:**

```bash
docker build -t sandtiger-research-takehome .
```

2. **Run the Docker image:**

```bash
docker build -t sandtiger-research-takehome .
```
